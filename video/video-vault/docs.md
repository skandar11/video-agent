# docs — сырьё и проекты роликов

Описание папок `../inbox/` и `../projects/`. Видео тяжёлое — **в git идёт только
монтажный лист**, остальное локально (см. `../../.gitignore`).

## inbox — сырьё

`../inbox/` — снятое, **ещё не разобранное**: файлы с телефона, камеры, диктофона.
Вне git. Пустеет, не копится: файл уходит в проект ролика (`montage ingest` пишет в
лист путь к файлу — сам файл остаётся там, где лежит; переносить его после ingest
нельзя, лист потеряет источник).

Как передавать с телефона — [[craft]] §Источник: AirDrop или кабель, не мессенджер.

## projects — ролики

`../projects/<YYYY-MM-DD-тема>/` — один ролик = одна папка (английский kebab-case,
дата — день съёмки или монтажа):

```
edit.json   монтажный лист — в git: источники, куски, переходы, карточки, сабы, звук
work/       промежуточное: слова, звук, сабы, карточки, graph.txt, commands.sh — вне git
out/        reel.mp4 · look.jpg (контактный лист) · qa.json — вне git
```

Ролик пересобирается из `edit.json` + исходников без памяти агента: все команды
ffmpeg прогона лежат в `work/commands.sh`.
